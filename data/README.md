# Данные для приложения

Приложение по кнопке Sync скачивает `index.json`, а затем все файлы, перечисленные в нём.
Если хоть один файл битый, Sync не применяется и остаются старые данные; в окне будет видно, какой файл и что не так.

## Как добавить банк руками

1. Создай `banks/<id>.json` (пример ниже) и, если хочешь логотип, положи PNG в `logos/` (квадрат, ~192×192).
2. Допиши путь в `index.json` → `"banks"`. Порядок в списке — порядок в приложении.
3. Push на GitHub → Sync в приложении.

Вместо шага 2 можно запустить `python -m mcc_tools.publish` из `pipeline/`: он проверит все файлы и сам пересоберёт `index.json`.

## index.json

```json
{
 "schema": 1,
 "generated": "2026-10-08T20:42:27Z",
 "banks": ["banks/tbank.json", "banks/sber.json"]
}
```

`generated` — только для информации.

## banks/<id>.json

```json
{
 "schema": 1,
 "id": "sber",
 "name": "Сбер",
 "color": "#21A038",
 "logo": "logos/sber.png",
 "source": {"url": "https://…pdf", "doc_id": "…", "doc_date": "2026-09-01"},
 "fallback": "1% на всё",
 "notes": ["Общая оговорка, показывается на странице банка"],
 "categories": [
  {
   "name": "Супермаркеты",
   "group": "Еда",
   "description": "Продуктовые магазины",
   "mcc": ["5411", "5422", "3000-3303"],
   "mcc_notes": {"5411": "только в будни"},
   "note": "Оговорка ко всей категории"
  }
 ],
 "excluded": ["4829", "6050-6051"],
 "excluded_notes": {"6050-6051": "Кроме покупок в акциях"}
}
```

Обязательны только `schema`, `id`, `name`; остальное можно опустить.

| Поле | Что значит |
|---|---|
| `id` | Уникальный латиницей; по нему приложение помнит, выключен ли банк |
| `color` | Цвет полоски банка, `#RRGGBB` |
| `logo` | PNG относительно `data/`; Sync скачивает его вместе с JSON. Не скачался — банк будет с цветным кружком |
| `mcc` | Коды строками; диапазон — `"3000-3303"` |
| `mcc_notes` | Оговорка к конкретному коду или диапазону — покажется, когда введён этот код |
| `excluded` | Коды, по которым кешбэка нет совсем → «Без кешбэка» |
| `excluded_notes` | Оговорка к коду из `excluded`. Начинается с «По описанию исключений:» — значит, банк описал исключение словами, а код подобран по смыслу |
| `fallback` | Что пишется, если код не в категориях и не в исключениях |

Код может входить в несколько категорий — приложение покажет все.
Категория без `mcc` (например, «Маркетплейсы» по списку магазинов) видна только на странице банка.

## Проверка после ручной правки

```sh
cd pipeline
python3 -m mcc_tools.check ../data/banks/alfa.json ../sources/alfa/*.pdf   # все ли коды из JSON есть в PDF
python3 -m mcc_tools.publish                                               # проверить файлы и пересобрать index.json
```
